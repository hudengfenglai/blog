## 前置准备

安装 Codex APP 前需要先装好三件套：

- **Git**
- **Node.js**
- **VS Code**

支持 Windows 和 Mac，功能基本一致。唯一差异：**Computer Use（自动操作电脑）目前只有 Mac 支持**。

---

## 一、界面布局

经典三栏布局：

- **左侧**：任务列表（项目 + 对话历史）
- **中间**：对话窗口
- **右侧**：多功能区（浏览器、文件树、终端）

快捷键：

- 新对话：`Ctrl+N`（Mac: `Cmd+N`）
- 搜索历史：`Ctrl+G`（Mac: `Cmd+G`）

## 二、沙箱权限系统

Codex 的权限系统以**沙箱**为核心，这是与 Claude Code 的本质区别。

### 沙箱默认规则

- 可读写项目文件夹内所有文件
- 不能修改沙箱外的文件
- 默认禁止联网

底层实现：Mac 用系统内置 Sandbox 机制，不靠模型自觉遵守。

### 三档权限模式

| 档位 | 说明 | 推荐度 |
| --- | --- | --- |
| 默认（人工审批） | 所有提权操作需手动确认 | 两星 |
| **自动审查**（推荐） | 小模型自动判断风险，低风险放行，高风险才人工审批 | 三星 |
| 完全访问 | 无视沙箱限制，可执行一切操作 | 谨慎 |

> 推荐日常使用**第二档：自动审查**，兼顾安全与便利。

## 三、对话窗口功能

### 上下文管理

- 右上角圆圈显示当前对话的上下文使用量
- 超限时自动压缩，也可输入 `/compress` 手动压缩
- **经验**：清空 > 压缩。完成一个任务后开新对话，避免历史干扰

### 模型选择

- 可选思考强度和模型版本（如 GPT-5.5）
- **快速模式**：速度提升 50%，但消耗 2 倍额度

### 额度限制

- 两个限额：**5小时限额** + **周限额**，任意一个到上限就不能用了
- 设置 → 剩余额度 查看

### 其他功能

- 语音输入
- 内置 AI 画图（GPT Image）
- 截图粘贴：`Ctrl+V` 直接粘贴图片进对话

## 四、Steer（引导）功能

当 AI 执行过程中理解偏了，不要等它跑完，及时**接管方向盘**：

1. 点击对话中的 **引导（Steer）按钮**，或按 `Ctrl+Enter`
2. 输入纠正指令，AI 立即调整方向

> 设置 → 跟进行为：可设置新指令是「排队」还是「直接引导」，推荐保持默认排队，需要时手动点引导按钮。

## 五、Git 与代码管理

### 初始化 Git 仓库

让 Codex 执行：`把项目初始化成一个 git 工程，注意排除掉不需要的文件`

初始化后右上角出现更多按钮，可一键用 VS Code 打开项目。

### 代码回滚（两步走）

1. **对话回滚**：找到要回退的位置 → 点击**分叉（Fork）按钮** → 派生到本地
2. **代码回滚**：在 VS Code Source Control 里复制目标 commit ID → 让 Codex 执行 `git reset` 回退

### Git Work Tree（并行开发）

本质：用 git 创建新分支，并把分支代码复制到独立文件夹，互不干扰。

```text
主文件夹（main）
├── 分支文件夹1（customer-rating）  ← 专注优化评价模块
└── 分支文件夹2（store-info）       ← 专注优化门店信息
```

操作：右键项目 → 创建永久工作树 → 各自开发 → 合并回主干 → 移除分支。

## 六、记忆系统

### 方法一：项目级 `AGENTS.md`

在项目根目录创建 `AGENTS.md`，每次对话自动读取作为上下文。

内容建议：

- 项目架构说明
- 技术栈
- 个人偏好（如“对 CSS 一窍不通，遇到样式问题用大白话解释”）

可以让 Codex 自动生成：`通读当前文件夹，把学到的项目知识保存到 AGENTS.md`

### 方法二：全局 `AGENTS.md`

设置 → 个性化 → 自定义指令，对所有项目生效。

文件位置：`C:\Users\{用户名}\.codex\AGENTS.md`

**推荐加入的全局提示词**：

```text
禁止使用脚本批量删除文件或目录。
只能使用 Remove-Item 一个一个文件删除。
如果必须批量删除，应停止操作，让用户手动处理。
```

### 方法三：实验性记忆功能

设置 → 启用记忆（实验性），可从聊天中自动生成记忆并带入新对话。

## 七、插件系统

左侧边栏 → 插件，进入官方插件市场。

### 常用插件

| 插件 | 功能 |
| --- | --- |
| GitHub | 读取仓库、管理 issue/PR |
| Gmail | 控制谷歌邮箱收发邮件 |
| Netlify | 一键部署静态/Next.js 项目（国内可直连） |
| Browser | 浏览器自动化 |
| Computer Use | 操作电脑（仅 Mac） |

### 自动化任务

对话完成后说：`把上述工作做成一个自动化，每周五下午4点执行`

左侧边栏 → 自动化，可查看、编辑、立即运行定时任务。

> Mac 用户：设置里开启「防止系统休眠」，确保定时任务能执行。

## 八、Skills（技能包）

Skills 是给 AI Agent 的专业技能包，把工作流封装成可复用的指令集。

### 三种安装方式

**1. 官方 Skills**

插件市场直接安装，如 Remotion（用代码生成动画视频）。

**2. 第三方 Skills**

从 GitHub 下载 `.md` 文件，放到项目的 `.codex/skills/` 目录下。

**3. 自制 Skills**

使用内置技能 `/skill-creator` 创建：

```text
/skill-creator
创建一个 skill：当我提供视频和字幕文件时，
第一步：读取字幕转换成 markdown 笔记，自动添加标点、划分段落，
       在涉及代码/UI/视觉内容的句子末尾添加截图标记
第二步：调用 ffmpeg 在截图标记位置截图，替换 markdown 中的占位符
```

## 九、MCP 服务器

设置 → MCP 服务器 → 添加服务器。

**案例：Supabase MCP**

1. Supabase 网站 → Connect → MCP 客户端 → 选 Codex → 复制 URL
2. Codex 里选「流式 HTTP」传输方式，填入 URL
3. 终端执行 `codex mcp login supabase` 完成授权
4. 重启 Codex

## 十、云端运行环境

前提：代码已同步到 GitHub。

流程：

1. 右上角推送代码到 GitHub
2. 运行模式 → 关联 Codex Web
3. 右上角 → 前往 Cloud
4. 选择仓库，输入需求
5. 完成后创建 PR → 审核 → Merge
6. 本地 VS Code → Source Control → Sync Changes 同步

适合场景：**出门在外用手机审批，让云端自动完成开发任务**。

## 十一、Computer Use（Mac 专属）

插件市场安装 Computer Use 插件，使用虚拟鼠标在后台操作，不占用当前窗口。

**案例**：

- 打开聊天软件发消息给老板
- 打开 GitHub 看板汇总进度，生成英文简报发送
- 配合自动化：每天下午5点自动汇总并发送日报
